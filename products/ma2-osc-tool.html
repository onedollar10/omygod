整合流程

以 OSC 橋接邏輯銜接 MA2 工作流，讓跨系統控制更直接。

01 INPUT 接收來自 QLab、Resolume、TouchDesigner 等系統的 OSC 訊號。
02 MAP 將地址與參數映射到 MA2 觸發指令與控制值。
03 VALIDATE 透過快速實測確認時序與 Cue 轉場一致性。
04 RUN 部署到正式演出流程，穩定完成 OSC 到控台的橋接。

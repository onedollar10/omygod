軟體簡介

Grid Tool for ETC Eos 是一款專為舞台燈光設計師打造的通道管理工具。它採用視覺化的網格介面，讓您可以直觀地管理和配置 ETC Eos 系列燈控台的通道佈局。透過 OSC 協定與燈控台即時通訊，大幅提升燈光編程效率。

佈局管理

佈局管理功能讓您可以儲存不同的通道配置，快速切換不同的燈具排列方式。

儲存佈局

操作步驟

  1. 調整通道到理想的網格位置
  2. 點擊「儲存佈局」按鈕
  3. 選擇佈局編號（1-10）
  4. 確認儲存

載入佈局

從佈局列表中選擇要載入的佈局編號，點擊「載入佈局」按鈕即可恢復該佈局的所有通道位置。

OSC 連動排序模式

Grid Tool 支援雙向 OSC 通訊，當燈控台發送通道選擇指令時，軟體可以根據不同的排序模式自動排列網格中的通道位置。

排序模式選擇

在介面中選擇「OSC 接收排序模式」：

圖 13：OSC 接收排序模式設定
排序模式 說明 適用場景
channel_number 按照通道號碼順序排列 快速查找特定編號的燈具
xy_position 按照燈具實際 3D 位置座標排列 視覺化燈具在舞台中的實際位置

Channel Number 模式

按照通道號碼從小到大依序排列在網格中。

工作原理

  • 滑鼠點選方格
  • 接收燈控台發送的通道

XY Position 模式

此模式會查詢燈控台中每個通道的 3D 位置座標，並根據實際的 X、Y 座標在網格中排列。

工作原理

  1. 接收燈控台發送的通道列表（如 "1-10,15,20"）
  2. 向燈控台查詢每個通道的 3D 位置資訊
  3. 根據回傳的 X、Y 座標計算網格位置
  4. 自動調整網格大小以容納所有通道
  5. 在網格上顯示對應的通道方塊

世界座標對應

XY Position 模式使用以下座標系統：

座標軸 燈控台 3D 座標 網格顯示
X 軸 舞台左負右正 網格左至右
Y 軸 舞台上正下負（高度） 網格上至下

自動網格調整

當使用 XY Position 模式時，如果接收到的通道座標超出目前網格範圍，系統會：

  • 自動計算所需的網格大小
  • 動態擴展網格以容納所有通道
  • 保持相對位置關係

⚠️ 使用須知

  • XY Position 模式需要燈控台支援 3D 位置回傳功能
  • 確保燈控台已設定正確的 3D 座標
  • 首次查詢位置時可能需要較長時間（依通道數量而定）
  • 如果查詢失敗，系統會自動切換回 channel_number 模式

群組製作與傳輸

Grid Tool 提供直觀的群組製作功能，透過顏色區分來快速建立和管理通道群組。相同顏色的通道會在傳輸時自動以圓括號 ( ) 包覆製作成子群組，方便在 ETC Eos 燈控台上進行批次選擇和控制。

顏色群組概念

為什麼使用顏色？

  • 視覺化辨識：一眼就能看出哪些通道屬於同一群組
  • 直觀操作：選擇顏色即可標記群組成員
  • 彈性分組：可自由組合不同顏色的子群組
  • 自動括號：相同顏色的通道傳輸時會自動以 ( ) 包覆

製作群組方式

有兩種方式可以製作顏色群組：

方法一：使用 X/Y 分組自動製作

自動分組步驟

  1. 設定「X 分組」或「Y 分組」數值（Blocks 模式）
  2. 或設定「XGroups」或「YGroups」數值（Groups 模式）
  3. 系統會自動根據位置為通道著色
  4. 相同顏色的通道即為同一子群組

方法二：手動選擇顏色指定

手動分組步驟

  1. 選擇要建立群組的通道（可多選）
  2. 點擊顏色選擇區的預設顏色方塊
  3. 或使用 CIE 色彩選擇器選擇自訂顏色
  4. 被選中的通道會立即套用該顏色

多選與拖曳

選擇模式

操作方式 功能 說明
單擊 單選 選中單一通道，取消其他選擇
Ctrl + 單擊 多選 加入或移除單個通道到選擇集合
Shift + 單擊 範圍選擇 選中上次選擇到本次點擊之間的所有通道
框選 區域選擇 在網格上拖曳繪製選擇框，選中範圍內的通道
圖 8：多選模式 - 選中的通道顯示紅色邊框

多通道拖曳

選中多個通道後，拖曳其中任意一個通道，所有選中的通道會同時移動，並保持相對位置關係。

智能位置調整

當拖曳多個通道時，如果目標區域空間不足，軟體會自動：

  • 嘗試在附近尋找合適位置
  • 保持通道間的相對位置
  • 如無法放置則恢復原位並顯示提示

對齊功能

對齊功能讓您可以快速將選中的燈具在 X 軸或 Y 軸上居中對齊，創造整齊的燈具排列。

X 軸居中對齊

將選中的燈具按照每一行（相同 Y 座標）進行 X 軸居中對齊。

  • 單數個燈具：中間燈具放在中心點，其餘左右對稱排列
  • 雙數個燈具：中間不放置，左右平均分佈

Y 軸居中對齊

將選中的燈具按照每一列（相同 X 座標）進行 Y 軸居中對齊。

圖 9：對齊功能 - X 軸與 Y 軸居中對齊

⚠️ 注意事項

對齊功能會檢查目標位置是否可用：

  • 如果目標位置超出網格邊界，操作將被取消
  • 如果目標位置被其他燈具佔用，會顯示錯誤提示
  • 多個燈具無法佔用同一位置

X/Y 分組

X/Y 分組功能使用視覺化顏色區分，幫助您快速識別燈具的分組情況。支援兩種模式：Blocks 模式和 Groups 模式。

Blocks 模式

按照指定大小的區塊進行分組。

使用方式

  1. 設定 X分組或 Y分組數值（大於 0）
  2. 系統會將網格劃分為指定大小的區塊
  3. 相同區塊內的通道會顯示相同顏色

Groups 模式

將燈具均勻分配為指定數量的群組。

使用方式

  1. 設定 XGroups 或 YGroups 數值（大於 0）
  2. 系統會將所有燈具均勻分配到指定數量的群組
  3. 同一群組的燈具顯示相同顏色
圖 10：X/Y 分組 - Block 模式和 Groups 模式

顏色組合

當同時啟用 X 和 Y 分組時，顏色會根據 X 和 Y 的顏色索引組合產生，讓您可以看到二維分組效果。

傳輸到 ETC 控台

完成群組製作後，點擊「Send EOS」按鈕即可將群組資料傳輸到 ETC Eos 燈控台。

傳輸格式說明

項目 說明
相同顏色通道 會被自動包覆在圓括號 ( ) 中，形成子群組
不同顏色群組 以空格分隔多個子群組
目標群組 ID 在「EOS Group ID」欄位設定，預設為 3000

傳輸步驟

  1. 確認網格中的通道已依顏色分組完成
  2. 設定「EOS Group ID」（如使用預設 3000 可略過）
  3. 點擊「Send EOS」按鈕
  4. 在確認對話框中檢視群組內容
  5. 確認後即傳輸至燈控台

⚠️ 注意事項

  • 傳輸前請確認 OSC 連線設定正確（IP 和 Port）
  • 目標群組 ID 如果已存在於燈控台，會被覆蓋
  • 建議先確認燈控台上的群組 ID 是否可用
  • 未設定顏色的通道會使用預設顏色（lightgrey）

FADE 功能提供專業的推桿控制介面，讓您可以透過推桿調整燈具的各種參數，並支援多種 Fan 模式，實現平滑的參數漸變效果。

圖 12：FADE 推桿控制介面

開啟 FADE 控制視窗

在主介面左側的「Fade Tools」區域，點擊「Open Fade」按鈕即可開啟 FADE 控制視窗。

推桿管理

功能 說明
新增推桿 點擊「+ 新增推桿」按鈕，一次新增 Y_Focus 和 X_Focus 兩個推桿組
刪除推桿 點擊「- 刪除推桿」按鈕移除最後一組推桿（至少保留兩個）
推桿滑動 上下拖曳推桿調整數值，即時發送 OSC 指令至燈控台
重置推桿 點擊「重置」按鈕將推桿數值歸零

Fan 模式

每個推桿都可以設定不同的 Fan 模式，控制參數在群組中的分佈方式：

模式 說明
Center 從群組中心向兩側擴散
Reverse 反向 Fan 效果
Mirror_Out 從兩側向中心鏡像
NO 不使用 Fan，直接設定

推桿參數設定

使用步驟

  1. 設定「GROUP」欄位：輸入目標群組編號（預設 3000）
  2. 選擇「MODE」：從下拉選單選擇 Fan 模式
  3. 拖曳推桿調整數值
  4. 或點擊「確認發送」按鈕手動發送指令

⚠️ 注意事項

  • 推桿移動時會即時發送 OSC 指令，請確保網路連線穩定
  • 數值範圍為 0 至 100，對應燈控台的參數百分比
  • Center 模式會發送兩個指令，中間有 0.2 秒延遲

Grid Tool 可以將網格中的通道配置發送到 ETC Eos 燈控台，包含通道號碼與對應的世界座標資訊。

故障排除

常見問題

Q1: 無法連接到燈控台

  • 確認 IP 位址正確（可使用 ping 測試）
  • 確認 Port 號與燈控台設定一致
  • 檢查 Windows 防火牆是否阻擋 Port 8000
  • 確認燈控台已啟用 OSC 接收功能
  • 確認電腦與燈控台在同一網段

Q2: 通道無法拖曳

  • 確認通道已被選中（顯示紅色邊框）
  • 檢查目標位置是否已有其他通道
  • 確認沒有超出網格邊界
  • 嘗試重新啟動軟體

Q3: 顏色無法發送到燈控台

  • 確認 OSC 連線正常
  • 檢查燈控台是否支援 CIE 色彩模式
  • 確認通道具有色彩屬性
  • 檢查 OSC Log 是否有錯誤訊息

Q4: 佈局載入失敗

  • 確認佈局檔案格式正確（JSON）
  • 檢查檔案是否損毀
  • 確認佈局編號未被佔用
  • 嘗試匯入 JSON 檔案而非直接載入

Q5: FADE 推桿無法控制燈控台

  • 確認 OSC 連線正常
  • 檢查 Group ID 是否正確（群組必須存在於燈控台）
  • 確認燈控台已選中該群組
  • 檢查 Fan 模式是否支援（部分模式需要特定燈控台版本）
  • 嘗試切換不同的 Fan 模式（Center、Reverse、Mirror_Out、NO）

Q6: XY Position 模式無法正確顯示位置

  • 確認燈控台已設定正確的 3D 座標
  • 檢查 OSC 監聽是否已啟用
  • 確認監聽埠號（預設 8001）未被其他程式佔用
  • 檢查 Windows 防火牆是否阻擋 UDP Port
  • 嘗試切換回 channel_number 模式再切換回來
  • 確認燈控台支援位置查詢指令（get/xyz）

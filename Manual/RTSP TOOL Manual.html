1. 軟體介紹

螢幕 RTSP 串流工具 是一套 Windows 桌面串流應用程式，可將「整個螢幕」或「指定視窗」即時推送成 RTSP 串流，供 VLC、OBS 等軟體接收。

工具內建自動下載 FFmpeg 與 MediaMTX，首次執行即可快速完成環境準備，適合現場導播、會議投放、節目側錄與跨設備監看。

雙來源模式

可選擇全螢幕或指定程式視窗進行串流。

低延遲推流

使用 FFmpeg + RTMP + MediaMTX，輸出 RTSP。

自動相依下載

首次啟動時自動下載所需執行檔，減少手動安裝。

即時狀態回饋

顯示串流燈號、FPS、位元率、累計時間。

2. 系統需求

項目需求
作業系統Windows 10 / Windows 11（64-bit）
網路環境建議同一個區域網路（LAN）內使用
磁碟空間至少 300MB（含相依下載）
首次啟動需可連外下載 FFmpeg / MediaMTX

3. 安裝與啟動

3.1 以 EXE 啟動

  1. 雙擊 螢幕RTSP串流.exe。
  2. 首次執行會自動下載相依元件。
  3. 下載完成後可直接進入主畫面。

3.2 首次啟動注意事項

  • 若防毒軟體跳出提示，請允許程式執行。
  • 若公司網路有代理或封鎖，可能導致下載失敗。
  • 可查看 logs/startup.log 與 logs/quick_start.log 進行除錯。

4. 介面說明

串流控制面板設定解析度/FPS/編碼器/位元率，開始或停止串流

5. 快速開始

5.1 串流整個螢幕

  1. 來源類型選擇「螢幕」。
  2. 選擇目標螢幕（例如 螢幕 1）。
  3. 按下「開始串流」。
  4. 將 RTSP 位址貼到 VLC/OBS 進行播放。

5.2 串流指定程式視窗

  1. 來源類型選擇「視窗」。
  2. 在清單中選擇你要分享的程式視窗。
  3. 按下「開始串流」。
  4. 確認燈號為綠色「串流中」。

6. 串流參數說明

參數建議值說明
解析度原始 / 1280x720 / 1920x1080解析度越高，畫質越好但耗能越高
幀率30 FPS一般畫面建議 30，動態高可選 60
編碼器libx264最穩定；有支援時可改用 NVENC / QSV
位元率4000 kbps數值越高畫質越好，頻寬需求也越高
預設速度ultrafast / fast / medium速度越快延遲越低，壓縮率通常較差

7. 播放端連線方式

軟體輸入位址說明
VLCrtsp://你的IP:8554/screen開啟網路串流後貼上即可
OBSrtsp://你的IP:8554/screen新增「媒體來源」並輸入網址
RTMP 來源（內部）: rtmp://127.0.0.1:1935/screen RTSP 輸出（對外）: rtsp://<本機IP>:8554/screen

8. EXE 部署建議

8.1 提供給其他電腦使用

  • 只要提供 螢幕RTSP串流.exe 即可啟動。
  • 第一次執行需連網下載相依元件。
  • 建議防火牆允許本程式的區域網路連線。

9. 常見問題

Q1：按「開始串流」後立刻停止

  • 請先確認來源視窗目前可見、未最小化。
  • 改用 libx264 測試是否可正常啟動。
  • 降低解析度與幀率後再試。

Q2：VLC/OBS 打不開 RTSP

  • 確認位址中的 IP 是推流電腦的區網 IP。
  • 確認播放端在同一網路。
  • 確認防火牆未阻擋 8554。

1. Overview

Screen RTSP Streaming Tool is a Windows desktop app that streams either your full screen or a selected window as an RTSP feed for VLC, OBS, and similar tools.

The app automatically downloads FFmpeg and MediaMTX on first launch, so setup is fast for live production, meetings, recording, and remote monitoring.

Dual Source Modes

Stream a full display or a single application window.

Low-Latency Pipeline

FFmpeg + RTMP + MediaMTX, then RTSP output.

Auto Dependency Download

Required binaries are downloaded automatically at first startup.

Live Status Feedback

Shows stream indicator, FPS, bitrate, and elapsed time.

3. Install and Launch

3.1 Start with EXE

  1. Double-click 螢幕RTSP串流.exe.
  2. Dependencies will be downloaded on first run.
  3. After download, the main interface opens automatically.

3.2 First-run Notes

  • Allow execution if antivirus prompts appear.
  • Corporate proxy/firewall policies may block downloads.
  • Check logs/startup.log and logs/quick_start.log for troubleshooting.

4. Interface Guide

5. Quick Start

5.1 Stream Full Screen

  1. Select source type: Monitor.
  2. Pick target monitor (for example, Monitor 1).
  3. Click Start Stream.
  4. Paste RTSP URL into VLC/OBS.

5.2 Stream One App Window

  1. Select source type: Window.
  2. Choose target app window in the list.
  3. Click Start Stream.
  4. Confirm green status indicator.

8. EXE Deployment Tips

8.1 Share with Other PCs

  • Distribute 螢幕RTSP串流.exe.
  • First launch needs internet for dependencies.
  • Allow LAN traffic through firewall for this app.

9. FAQ

Q1: Stream stops right after Start

  • Make sure source window is visible and not minimized.
  • Try libx264 first.
  • Lower resolution/FPS and retry.

Q2: VLC/OBS cannot open RTSP

  • Use the streamer PC's LAN IP in URL.
  • Ensure both devices are on the same network.
  • Verify firewall is not blocking port 8554.

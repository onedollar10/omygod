Introduction

Grid Tool for ETC Eos is a professional utility designed for lighting designers. It uses a visual grid interface to intuitively manage and configure channel layouts for ETC Eos series consoles. It syncs with the console via OSC protocol, significantly enhancing programming efficiency.

Fig 1: Grid Tool for ETC Eos Main Interface

Key Features

🎨 Visual Grid

Intuitive grid interface, see channel positions at a glance.

📐 Multiple Selection

Supports single, Ctrl multi, Shift range, and marquee selection.

🎨 CIE Color Picker

Professional CIE 1931 color space picker.

📋 Layout Manager

Save and load multiple channel layout configurations.

📡 OSC Communication

Real-time data transmission to ETC Eos consoles.

🎯 Alignment Tools

Center align on X/Y axis for perfectly arranged fixtures.

🌈 X/Y Grouping

Block and Groups modes for visual grouping.

🎚️ FADE Control

Professional slider interface with multiple Fan gradient modes.

🔄 Bidirectional Sync

Auto-sort by Channel Number or XY Position.

OSC Sync Sort Mode

Grid Tool supports bidirectional OSC. When the console sends channel selection commands, the software can auto-arrange channels based on sorting modes.

Mode Selection

Choose the mode in the "OSC Receive Sort Mode" dropdown:

Fig 13: OSC Receive Sorting Configuration
Sort Mode Description Use Case
channel_number Arranged by channel ID sequence. Quickly find specific numbered fixtures.
xy_position Arranged by actual 3D coordinates. Visualized layout matching physical stage positions.

XY Position Mode

This mode queries the console for each channel's 3D coordinates and arranges them on the grid accordingly.

Workflow

  1. Receive channel list from console (e.g., "1-10,15,20").
  2. Query console for 3D position data of each channel.
  3. Calculate grid positions based on X, Y coordinates.
  4. Auto-resize grid to fit all channels if needed.
  5. Render channel blocks on the grid.

Coordinate Mapping

Axis Console 3D Coord Grid Display
X Axis Stage Left (-) to Right (+) Left to Right
Y Axis Stage Height (Up + / Down -) Top to Bottom

⚠️ Notice

XY Position mode requires the console to support 3D coordinate feedback. If query fails, system defaults back to channel_number mode.

Group Creation & Transfer

Create groups intuitively using color coding. Identical colors are automatically wrapped in parentheses ( ) when sent to the console.

Color Grouping Concept

Why use colors?

  • Visual Recognition: One glance to see who belongs where.
  • Intuitive Operation: Pick a color to tag members.
  • Flexible: Combine different sub-groups easily.
  • Auto-Parentheses: Syncing handles the syntax for you.

Creation Methods

Method 1: X/Y Auto-Grouping

Set "Blocks" or "Groups" values. System assigns colors based on grid position automatically.

Method 2: Manual Assignment

Select channels (Ctrl/Shift select) and click a color block or use the CIE picker.

Sending to ETC Console

After completing group creation, click the "Send EOS" button to transmit group data to the ETC Eos console.

Transmission Format

Item Description
Same Color Channels Automatically wrapped in parentheses ( ) to form sub-groups
Different Color Groups Separated by spaces as multiple sub-groups
Target Group ID Set in "EOS Group ID" field, default is 3000

Transmission Steps

  1. Confirm channels in grid are grouped by color
  2. Set "EOS Group ID" (skip if using default 3000)
  3. Click "Send EOS" button
  4. Review group content in confirmation dialog
  5. Confirm to transmit to console

⚠️ Important Notes

  • Ensure OSC connection settings are correct (IP and Port) before transmission
  • Target group ID will be overwritten if it already exists on console
  • Recommended to verify group ID availability on console first
  • Un-colored channels use default color (lightgrey)

FADE Slider Control

FADE provides a professional slider interface for adjusting fixture parameters with multiple Fan modes for smooth gradient effects.

Fig 12: Professional FADE Slider Interface

Opening FADE Control Window

In the "Fade Tools" area on the left side of the main interface, click the "Open Fade" button to open the FADE control window.

Slider Management

Function Description
Add Slider Click "+ Add Slider" button to add a pair of Y_Focus and X_Focus sliders
Remove Slider Click "- Remove Slider" button to remove the last slider pair (minimum 2 sliders)
Slider Drag Drag sliders up/down to adjust values, sending OSC commands to console in real-time
Reset Sliders Click "Reset" button to zero all slider values

Fan Modes

Each slider can be set to different Fan modes to control parameter distribution across the group:

Mode Description
Center Spreads from group center to both sides
Reverse Reverse Fan effect
Mirror_Out Mirrors from both sides toward center
NO No Fan, direct setting

Slider Parameter Setup

Usage Steps

  1. Set "GROUP" field: Enter target group number (default 3000)
  2. Select "MODE": Choose Fan mode from dropdown
  3. Drag sliders to adjust values
  4. Or click "Confirm Send" button to manually send commands

⚠️ Important Notes

  • Sliders send OSC commands in real-time during movement, ensure stable network connection
  • Value range is 0 to 100, corresponding to percentage on console
  • Center mode sends two commands with 0.2 second delay between them

RTSP Stream & Multi-Region Composition

Grid Tool now supports direct desktop or window capture via FFmpeg, allowing multiple sources to be composed into a single RTSP stream for MediaMTX or other players.

Fig 13: RTSP Streaming Configuration and Options

Key Features

  • Multi-Region: Add multiple capture areas (Regions) with custom source and output coordinates.
  • Text Overlay: Overlay custom watermark text on the stream with adjustable positioning.
  • High Performance: Native FFmpeg processing without external dependencies.

Configuration

  1. Go to "Tools" -> "Settings" -> "RTSP Streaming" tab.
  2. Set output resolution and RTSP target URL.
  3. Click "Manage Capture Regions" to add or adjust areas.
  4. Set watermark text in the "Advanced Composition" section.
  5. Click "Start Stream" to begin transmission.

UI Module Dragging & Reordering

For a more flexible user experience, functional modules in the sidebar (such as Fade Tools, Layout Manager, Color Picker, etc.) now support free dragging.

How to Use

Hover over a module's header or background space, then press and hold the left mouse button to drag it up or down. The order is automatically saved and restored on next launch.

Troubleshooting

Common Issues

Q1: Cannot connect to lighting console

  • Verify the IP address is correct (use ping to test)
  • Confirm the Port number matches console settings
  • Check if Windows Firewall is blocking Port 8000
  • Ensure OSC receive function is enabled on the console
  • Confirm computer and console are on the same network segment

Q2: Channels cannot be dragged

  • Confirm channel is selected (shows red border)
  • Check if target position already has another channel
  • Ensure not exceeding grid boundaries
  • Try restarting the software

Q3: Color cannot be sent to console

  • Confirm OSC connection is normal
  • Check if console supports CIE color mode
  • Ensure channels have color attributes
  • Check OSC Log for error messages

Q4: Layout loading failed

  • Confirm layout file format is correct (JSON)
  • Check if file is corrupted
  • Confirm layout number is not occupied
  • Try importing JSON file instead of direct loading

Q5: FADE slider cannot control console

  • Confirm OSC connection is normal
  • Check if Group ID is correct (group must exist on console)
  • Ensure console has selected that group
  • Check if Fan mode is supported (some modes require specific console version)
  • Try switching to different Fan modes (Center, Reverse, Mirror_Out, NO)

Q6: XY Position mode cannot display positions correctly

  • Confirm console has correct 3D coordinates set
  • Check if OSC listening is enabled
  • Confirm listening port (default 8001) is not occupied by other programs
  • Check if Windows Firewall is blocking UDP Port
  • Try switching back to channel_number mode then back to xy_position
  • Confirm console supports position query commands (get/xyz)

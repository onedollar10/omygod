軟體簡介

OSC Absolute Timecode Tool 是一款專業的時間碼同步工具，專為舞台燈光設計師與技術人員打造。它能透過 OSC 協定與 ETC/EOS 燈控台通訊，並支援輸出標準 SMPTE LTC（音訊格式）與 MTC（MIDI 格式）時間碼。

v6.0 版本引入了 MTC (MIDI Timecode) 支援，讓使用者能透過 MIDI 介面或虛擬 MIDI 埠進行數位傳輸，並整合了全新的統一設定視窗。

LTC 時間碼輸出

LTC (Linear Timecode) 是標準的 SMPTE 時間碼格式，可透過音訊輸出傳送至外部設備。

圖 9：LTC 控制面板，包含開關、音量滑桿與裝置選擇

LTC 控制項

控制項 功能
LTC Out 開關 啟用/停用 LTC 輸出
Vol 滑桿 調整 LTC 訊號音量 (0-100%)
裝置選單 選擇音訊輸出裝置
狀態指示 顯示 LTC 目前狀態

狀態指示燈

狀態 顏色 說明
⚫ OFF 灰色 LTC 輸出關閉
🟢 ON 綠色 LTC 輸出開啟，待機中
🟢 RUNNING 亮綠色 LTC 正在輸出時間碼
🟡 PAUSED 黃色 LTC 暫停中

⚠️ 重要提醒

請選擇「獨立音訊裝置」輸出 LTC，不要與主喇叭共用，以避免時間碼與音樂混音。

聲道配置說明：

  • LTC 輸出開啟時：左聲道 (L) 輸出 LTC 時間碼訊號，右聲道 (R) 輸出音訊聲音
  • LTC 輸出關閉時：左聲道 (L) 和右聲道 (R) 都輸出音訊聲音（立體聲）

MTC 時間碼輸出

MTC (MIDI Timecode) 是透過 MIDI 協定傳送的時間碼，適合與 QLab、Resolume 或支援 MIDI 的燈控台連動。

MTC 優勢

• 無需佔用音訊聲道

• 數位傳輸，訊號更純淨

• 支援虛擬 MIDI 埠 (如 loopMIDI)

MTC 狀態指示

狀態 顏色 說明
⚫ OFF 灰色 MIDI 輸出未開啟
🟢 ON 綠色 MIDI 埠已連接，待命中
🟢 RUNNING 亮綠色 正積極傳送 MIDI Timecode 數據

在播放過程中，您可以在介面上即時監控 MTC 的傳輸狀態，確保與燈控台或媒體伺服器精確同步。

⚠️ ETC 版本適配 (重要)

針對 ETC Eos 系統的版本差異，現在可手動選擇：

  • 3.3.5 以上： 使用 /Timecode/ 指令路徑。
  • 3.3.4 以下： 使用 /Time_Code/ 指令路徑。

這解決了舊版控台無法接收時間碼標記的問題。

重要：控台版本選擇

為了適配不同世代的 ETC EOS 軟體，我們新增了版本選擇功能：

標記 Cue (Marking Cues)

操作步驟

  1. 播放音樂
  2. 到達需要標記的時間點
  3. 按下「Mark Cue」按鈕
  4. 系統會發送 OSC 指令至燈控台並記錄到 Cue Log

Cue List 自動同步與 Record 自動記錄

軟體具備與燈控台深度整合的自動化功能：

📋 獲取 Cue List

軟體可向燈控台發送請求，獲取完整的 Cue 清單並載入至軟體中，省去手動輸入的麻煩。

⏺️ Record 自動記錄

開啟「Record」功能後，當您在燈控台按下 GO 鍵，軟體會即時捕捉指令，並自動將當下的音樂時間碼寫入該 Cue 點，完美契合您的現場編排節奏。

故障排除

常見問題

Q1: 無法連接到燈控台

  • 確認 IP 位址正確（可使用 ping 測試）
  • 確認 Port 號與燈控台設定一致
  • 檢查 Windows 防火牆是否阻擋 Port 8000
  • 確認燈控台已啟用 OSC 接收功能

Q2: LTC 輸出沒有聲音

  • 確認 LTC Out 開關已開啟
  • 確認選擇了正確的音訊裝置
  • 檢查音量是否設定太低
  • 確認裝置沒有被其他程式占用

Q3: sACN 無法接收訊號

  • 確認電腦與燈控台在同一網段
  • 檢查 Windows 防火牆是否阻擋 UDP Port 5568
  • 確認 Universe 編號一致
  • 確認燈控台有輸出 sACN 訊號

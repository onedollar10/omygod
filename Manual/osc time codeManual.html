軟體簡介

OSC Absolute Timecode Tool 是一款專業的時間碼同步工具，專為舞台燈光設計師與技術人員打造。它能透過 OSC 協定與 ETC/EOS 燈控台通訊，並輸出標準 SMPTE LTC 時間碼。

圖 1：OSC Absolute Timecode Tool 主介面

主要特色

🎵 播放清單管理

支援多音軌管理、自動續播、獨立時間碼偏移

📡 OSC 通訊

即時發送時間碼至 ETC/EOS 燈控台

🔊 LTC 輸出

透過音訊介面輸出標準 SMPTE 時間碼

📊 波形視覺化

即時顯示音訊波形，支援縮放與點擊定位

📝 Cue 標記系統

快速標記、編輯、匯入/匯出 Cue 時間碼

💾 WAV 輸出

輸出雙聲道 WAV（左=LTC，右=音樂）

🎛️ sACN 遙控

透過 DMX 網路遙控播放

LTC 時間碼輸出

LTC (Linear Timecode) 是標準的 SMPTE 時間碼格式，可透過音訊輸出傳送至外部設備。

圖 9：LTC 控制面板，包含開關、音量滑桿與裝置選擇

LTC 控制項

控制項 功能
LTC Out 開關 啟用/停用 LTC 輸出
Vol 滑桿 調整 LTC 訊號音量 (0-100%)
裝置選單 選擇音訊輸出裝置
狀態指示 顯示 LTC 目前狀態

狀態指示燈

狀態 顏色 說明
⚫ OFF 灰色 LTC 輸出關閉
🟢 ON 綠色 LTC 輸出開啟，待機中
🟢 RUNNING 亮綠色 LTC 正在輸出時間碼
🟡 PAUSED 黃色 LTC 暫停中

⚠️ 重要提醒

請選擇「獨立音訊裝置」輸出 LTC，不要與主喇叭共用，以避免時間碼與音樂混音。

聲道配置說明：

  • LTC 輸出開啟時：左聲道 (L) 輸出 LTC 時間碼訊號，右聲道 (R) 輸出音訊聲音
  • LTC 輸出關閉時：左聲道 (L) 和右聲道 (R) 都輸出音訊聲音（立體聲）

OSC 通訊與 Cue 標記

OSC 設定

圖 10：OSC 連線設定 - IP 與 Port
圖 11：完整 OSC 設定區域包含 Mark Cue 按鈕

在 OSC 設定區域中，ETC IP 欄位輸入燈控台的 IP 位址，Port 欄位輸入 OSC 接收埠（預設 8000），Cue # / Path 欄位輸入 Cue 編號。

Mark Cue（標記 Cue）

操作步驟

  1. 播放音樂
  2. 到達需要標記的時間點
  3. 按下「Mark Cue」按鈕
  4. 系統會發送 OSC 指令至燈控台並記錄到 Cue Log

故障排除

常見問題

Q1: 無法連接到燈控台

  • 確認 IP 位址正確（可使用 ping 測試）
  • 確認 Port 號與燈控台設定一致
  • 檢查 Windows 防火牆是否阻擋 Port 8000
  • 確認燈控台已啟用 OSC 接收功能

Q2: LTC 輸出沒有聲音

  • 確認 LTC Out 開關已開啟
  • 確認選擇了正確的音訊裝置
  • 檢查音量是否設定太低
  • 確認裝置沒有被其他程式占用

Q3: sACN 無法接收訊號

  • 確認電腦與燈控台在同一網段
  • 檢查 Windows 防火牆是否阻擋 UDP Port 5568
  • 確認 Universe 編號一致
  • 確認燈控台有輸出 sACN 訊號

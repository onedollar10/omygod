Introduction

OSC Absolute Timecode Tool is a professional timecode synchronization utility designed for lighting designers and technical crews. It communicates with ETC/EOS consoles via OSC protocol and supports both SMPTE LTC (Audio) and MTC (MIDI) timecode output.

Version 6.0 introduces MTC (MIDI Timecode) support, enabling digital transmission via MIDI interfaces or virtual MIDI ports, alongside a brand new Unified Settings window.

Fig 1: OSC Absolute Timecode Tool 6.0 Interface Overview

Key Features

🎵 Playlist Management

Support for multi-track management, auto-next, and independent offsets.

📡 OSC Communication

Real-time timecode transmission to ETC/EOS lighting consoles.

🔊 LTC Output

Output standard SMPTE timecode via audio interfaces.

📊 Waveform Visualization

Real-time waveform display with zoom and click-to-seek support.

📝 Cue Marking System

Quickly mark, edit, and import/export Cue timecode logs.

💾 WAV Export

Export dual-channel WAV files (Left=LTC, Right=Music).

🎹 MTC Output

Digital MIDI timecode transmission without using audio channels.

🎛️ sACN Remote

Remote playback control via DMX network (sACN).

LTC Timecode Output

Outputs standard Linear Timecode (LTC) via audio channels.

Fig 9: LTC Panel - Switch, Gain, and Device selection

Status Indicators

Status Color Description
⚫ OFF Gray LTC output disabled
🟢 ON Green LTC output enabled, standby
🟢 RUNNING Bright Green LTC actively outputting timecode
🟡 PAUSED Yellow LTC paused

⚠️ Important Reminder

Please select a "dedicated audio device" for LTC output. Do not share with main speakers to avoid mixing timecode with music.

Channel Configuration:

  • When LTC Output is ON: Left Channel (L) outputs LTC timecode signal, Right Channel (R) outputs audio
  • When LTC Output is OFF: Both Left (L) and Right (R) channels output audio (stereo)

MTC Timecode Output

MTC (MIDI Timecode) is timecode sent via the MIDI protocol, suitable for integration with QLab, Resolume, or MIDI-capable lighting consoles.

Advantages of MTC

• Does not occupy audio channels

• Digital transmission for cleaner signals

• Supports virtual MIDI ports (e.g., loopMIDI)

MTC Status Indicators

Status Color Description
⚫ OFF Gray MIDI output disabled
🟢 ON Green MIDI port connected, standby
🟢 RUNNING Bright Green Actively transmitting MIDI Timecode data

Monitor MTC transmission status in real-time to ensure precise synchronization with consoles or media servers during playback.

Console Settings

Fig 11: Console Settings Window - Configure IP, Port, and Console Version

Important: Console Version Selection

To ensure compatibility across different generations of ETC EOS software, we've added a version selector:

• 3.3.5+: Uses the latest OSC path commands (e.g., /Timecode/).

• 3.3.4-: Uses legacy path formats (e.g., /Time_Code/).

* If your console is not receiving timecode, try switching this version setting.

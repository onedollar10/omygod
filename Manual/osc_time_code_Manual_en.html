Introduction

OSC Absolute Timecode Tool is a professional timecode synchronization utility designed for lighting designers and technical crews. It communicates with ETC/EOS consoles via OSC protocol and outputs standard SMPTE LTC timecode.

Fig 1: OSC Absolute Timecode Tool Main Interface

Key Features

🎵 Playlist Management

Support for multi-track management, auto-next, and independent offsets.

📡 OSC Communication

Real-time timecode transmission to ETC/EOS lighting consoles.

🔊 LTC Output

Output standard SMPTE timecode via audio interfaces.

📊 Waveform Visualization

Real-time waveform display with zoom and click-to-seek support.

📝 Cue Marking System

Quickly mark, edit, and import/export Cue timecode logs.

💾 WAV Export

Export dual-channel WAV files (Left=LTC, Right=Music).

🎛️ sACN Remote

Remote playback control via DMX network (sACN).

LTC Timecode Output

Outputs standard Linear Timecode (LTC) via audio channels.

Fig 9: LTC Panel - Switch, Gain, and Device selection

Status Indicators

Status Color Description
⚫ OFF Gray LTC output disabled
🟢 ON Green LTC output enabled, standby
🟢 RUNNING Bright Green LTC actively outputting timecode
🟡 PAUSED Yellow LTC paused

Device Modes

LTC Output Left Channel (L) Right Channel (R)
ON LTC Signal Music (Mono)
OFF Music (Mono) Music (Mono)

⚠️ Important Reminder

Please select a "dedicated audio device" for LTC output. Do not share with main speakers to avoid mixing timecode with music.

Channel Configuration:

  • When LTC Output is ON: Left Channel (L) outputs LTC timecode signal, Right Channel (R) outputs audio
  • When LTC Output is OFF: Both Left (L) and Right (R) channels output audio (stereo)

Troubleshooting

Common Issues

Q1: Cannot connect to lighting console

  • Verify the IP address is correct (use ping to test)
  • Confirm the Port number matches console settings
  • Check if Windows Firewall is blocking Port 8000
  • Ensure OSC receive function is enabled on the console

Q2: No LTC output sound

  • Confirm LTC Out switch is turned ON
  • Verify the correct audio device is selected
  • Check if volume is set too low
  • Ensure the device is not occupied by another program

Q3: sACN cannot receive signal

  • Confirm computer and console are on the same network segment
  • Check if Windows Firewall is blocking UDP Port 5568
  • Verify Universe number matches
  • Ensure console is outputting sACN signal

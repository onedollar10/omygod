Introduction

ETC Cue Screenshot Logger is a professional tool designed for lighting designers and stage technicians. It communicates with ETC/EOS consoles via OSC protocol to automatically capture stage screenshots when a Cue is completed or Channel is set, providing comprehensive project management and report export features.

Fig 1: ETC Cue Screenshot Logger Main Interface

Key Features

🎯 Cue Mode

Auto-detects Cue fire events, captures screenshots, and logs Cue number and time.

💡 CH Mode

Supports Chan command detection, ideal for logging parameter settings scenes.

📹 Video Input

Supports USB cameras, NDI network video, and RTSP streams.

🎬 Video Recording

Built-in recording with automatic Cue time-stamping.

📊 Complete Logs

Logs Cue #, duration, screenshots, notes, and other complete information.

📁 Project Management

Supports saving/loading projects for managing multiple show projects.

📄 Report Export

One-click export to Excel and PDF reports for sharing and archiving.

🔄 Overwrite Mode

Supports updating records by overwriting, convenient for correcting screenshots.

📡 sACN DMX Trigger

Supports receiving sACN DMX signals with configurable trigger channel and threshold for automatic capture.

sACN DMX Trigger Setup

The software supports receiving DMX signals via sACN (Streaming ACN) protocol. You can configure specific DMX channels as screenshot trigger conditions, perfect for synchronizing captures with lighting effects.

sACN Features

📡 sACN Signal Reception

Automatically receives sACN DMX signals from the network without additional hardware.

🎯 Custom Trigger Channel

Specify any DMX channel (1-512) as the trigger source.

⚡ Edge Trigger

Triggers only once when value rises above threshold, preventing duplicate captures.

🎮 Manual Trigger Control

Manually control screenshot timing via DMX signals, synchronized with lighting effects.

sACN Configuration Steps

Setup Procedure

  1. Click "Settings" menu → "Open Settings..."
  2. Enable sACN reception in the "sACN Settings" section
  3. Set Universe number (default is 1)
  4. Set trigger channel (1-512, e.g., channel 1)
  5. Set trigger threshold (0-255, e.g., 128)
  6. Click "OK" to save settings

Trigger Logic

Setting Default Description
Universe 1 sACN Universe number (1-63999)
Trigger Channel 1 DMX channel number (1-512)
Trigger Threshold 128 Screenshot triggers when DMX value exceeds this (0-255)

Edge Trigger Mechanism

The software uses edge triggering to capture once when DMX value rises:

  • When DMX value changes from ≤ threshold to > threshold: Trigger capture
  • When DMX value remains > threshold: Do not re-trigger
  • When DMX value changes from > threshold to ≤ threshold: Reset trigger state

This ensures each lighting change triggers only one screenshot, avoiding duplicate records.

Usage Example

Example: Sync with Lighting Effects

Suppose you want to capture screenshots when specific lighting effects trigger:

  1. On the console, assign a dedicated DMX channel (e.g., channel 512) as the trigger signal
  2. In the software, set sACN Universe to 1, trigger channel to 512, threshold to 1
  3. In Cues requiring capture, set channel 512 to 255
  4. When that Cue executes, the software automatically captures the current frame

⚠️ Network Configuration Notes

  • Ensure the PC is on the same subnet as the sACN source device
  • sACN uses Multicast addresses (239.255.0.0/16) - ensure network devices support IGMP
  • Windows Firewall may need to allow sACN-related network traffic

CH Mode Operation

CH Mode is ideal for documenting static parameter settings. Captured when Chan commands are detected.

Fig 11: CH Mode tracking specified Channels

CH Mode Workflow

Automatic Workflow

  1. Software receives Chan command (e.g., Chan 1).
  2. Displays current Chan ID.
  3. Waits for Level command (e.g., @ Full).
  4. Captures screenshot after a 1-second delay.
  5. Entry appears in log table.

Supported Command Formats

Format Meaning Example
Chan X Single Channel Chan 1
Chan X + Y Multiple Channels Chan 1 + 5
Chan X Thru Y Channel Range Chan 1 Thru 3

⚠️ Auto-Delay

To ensure lighting output has fully settled, the software waits 1 second after a Level command before capturing.

Manual Screenshot Feature

Beyond automation, you can capture manually to add missing entries or correct existing ones.

Overwrite Mode

When a row is selected, clicking "📷 Manual Screenshot" will:

  • Update ONLY the screenshot for that row.
  • Keep existing metadata (Cue/Chan ID, etc.).
  • Ideal for fixing entries where the original shot was poorly timed.

Manual Trigger via sACN DMX Signal

When sACN is enabled, you can also manually control screenshot timing via DMX signals:

sACN Manual Trigger Process

  1. Enable sACN reception in settings and configure the trigger channel
  2. When the configured DMX channel value exceeds the threshold, the software automatically captures
  3. Only updates the screenshot without changing Cue/Chan information

Troubleshooting

Q1: No connection to console?

  • Check IP in both software and console.
  • Verify firewall isn't blocking UDP 8000.
  • Confirm OSC Output is ON on the console.
  • Ensure console has enabled OSC output function

Q2: Video source won't connect?

  • Ensure USB camera is properly connected
  • Confirm NDI source is ON and on same subnet
  • Verify RTSP stream URL is correct
  • Try restarting the software

Q3: Auto-capture not working?

  • Ensure "Start Recording" button is clicked (button should be RED)
  • Verify "OSC Active" status is shown in bottom bar
  • Confirm console is sending Cue signals
  • Check if in Cue mode (not CH mode)

Q4: CH mode not capturing?

  • Ensure "Start Recording" button is clicked
  • Confirm switched to CH mode
  • Verify console Chan command format is correct
  • Ensure Level command follows Chan command (e.g., @ Full)

Q5: PDF export shows squares for Chinese characters?

  • Ensure "Microsoft JhengHei" font is installed on system
  • If not installed, software will automatically try other Chinese fonts

2. Quick Start Guide (run.bat)

The controller runs on an ultra-lightweight standalone Python bridge server. You can launch the system with a single click using run.bat:

🚀 Windows Launch Procedure

  1. Double-click run.bat in the root directory.
  2. The standalone Python server will initialize and listen on HTTP Port 8080.
  3. Open Chrome, Edge, Safari, or tablet browser at http://localhost:8080 (or your LAN IP, e.g. http://192.168.1.100:8080).
  4. Click the Settings (⚙) gear icon in the top right corner, input your ETC Console IP, and click Save to connect!

3. ETC Eos Console OSC Configuration

To enable seamless bi-directional communication between your ETC Eos console (or ETCnomad) and this controller, configure the console as follows:

🛠️ ETC Eos Console Setup Steps

  1. On the Eos console, press Displays (or open Browser) → select Setup.
  2. Navigate to System Settings → choose Show Control.
  3. Under the OSC tab, configure the following parameters:
    • OSC RX (Receive): Set to Enabled.
    • OSC TX (Transmit): Set to Enabled.
    • OSC UDP RX Port: Set to 8000 (matches Send Port).
    • OSC UDP TX Port: Set to 8001 (matches Listen Port).
    • OSC UDP TX IP Address: Enter the IP of this PC/phone, or set to 255.255.255.255 (Broadcast).
    • String RX / TX: Set to Enabled.
  4. Return to Live view. The top connection status banner will turn green: Connected to Eos at [IP]:8000.

⚠️ Network & Firewall Note

Ensure that both the controller device and the ETC console are connected to the same Wi-Fi router or subnet. In Windows, ensure the Windows Defender Firewall allows incoming/outgoing UDP traffic on ports 8000 and 8001.

7. 🎛️ Encoder Customization & Step Sizes

Every single encoder wheel is completely customizable! Clicking on the parameter name label (e.g. "Pan", "Zoom") opens the Custom Encoder configuration dialog.

Figure 6: Custom Encoder Modal (Category, Parameter, Custom Label, Step Size Selection)

🛠️ How to Customize an Encoder

  1. On the ENCODERS or FOCUS tab, click the parameter name label atop any wheel.
  2. In the modal, select the desired Parameter Category (e.g. Beam / Optics or Shutter).
  3. Choose the exact Control Parameter from the dropdown list (e.g. Iris or Frost).
  4. (Optional) Enter a personalized Display Label.
  5. Choose the Step Size sensitivity:
    • Standard (1.0): Default for general attributes.
    • Fine (0.5): Ideal for smooth color mixing or focus edge.
    • Ultra Precision (0.1): Ideal for framing shutters and pinpoint pan/tilt calibration.
    • Fast (2.0): Rapid coarse repositioning.
  6. Click Save Assignment to apply immediately.

9. CIE COLOR Tab: CIE 1931 Color Studio

The CIE COLOR Studio Tab expands the CIE 1931 xyY chromaticity diagram to full screen for lighting designers seeking precise color calibration and smooth multi-point fan gradients.

Figure 8: CIE COLOR Studio Tab (Full-scale Diagram + P1/P2 Gradient + Color Temp Swatches)

🎨 How to Mix Color via CIE 1931

  1. Enter the target Group number in the Target GROUP ID box (default 3000).
  2. Select Point 1 (P1 Start) and drag the cursor to your desired color (coordinates update live, e.g. 0.3333, 0.3333).
  3. To create a color gradient across fixtures, select Point 2 (P2 End) and position the second point.
  4. Or click any preset chip: 3200K Tungsten, 5600K Daylight, Red, Green, Blue, Amber.
  5. Click SEND COLOR at the bottom to dispatch /eos/color/xy OSC packets to the ETC console.

13. 🎙️ Voice Recognition & Gemini AI Brain

The controller introduces a revolutionary dual-engine voice control architecture: a Local 1ms Offline NLP Parser for instant standard commands, combined with a Gemini 3.1 Live WebSocket AI Brain for natural language conversational lighting control!

Figure 14: Voice Recognition Dynamic Waveform Interface (Hold to Speak, Release to Fire)

🎤 How to Use Voice Control

  1. Tap the 🎙️ icon in the top header or press and hold the VOICE button on the REMOTE keypad.
  2. A dynamic glowing soundwave modal will appear showing Listening for command....
  3. Speak your command naturally (e.g., "Channel 1 Full", "1 thru 10 at 50", or "Goto Cue 5").
  4. Release the button or stop speaking: the system parses the sentence and dispatches the exact OSC syntax string to the console in under 0.1 seconds!

💡 Dual-Engine Advantage

  • Local Engine (1ms latency): Works 100% offline without internet; instantly executes standard commands (e.g. "Chan 1 50", "Group 2 Out", "Goto Cue 10").
  • Gemini AI Brain (Conversational Reasoning): Handles complex natural phrasing (e.g. "Make the front wash warm amber", "Dim all side lights by half", "Next cue").

15. Troubleshooting & FAQ

❓ Q1: Top bar shows "Disconnected from console" and buttons do not respond?

  • Verify Console IP: Open Settings ⚙ and verify the Console IP (press About on your Eos console to confirm its active IP).
  • Wi-Fi Subnet Check: Ensure your phone/PC and the console are on the same Wi-Fi subnet and that "AP Isolation" is disabled on the router.
  • Show Control Setting: Verify in Eos Setup > System Settings > Show Control > OSC that OSC RX and OSC TX are both Enabled on ports 8000 / 8001.

❓ Q2: Voice input does not activate or requests microphone permission?

  • Browser Microphone Permission: Allow microphone access when prompted by the browser.
  • HTTPS / Localhost Policy: Browsers require HTTPS for Web Speech API when accessing remote IP addresses. For mobile phones, install the included Android APK for fully native standalone speech recognition.

❓ Q3: How to run full-screen on Android or iPad / iPhone?

  • Android Devices: Run install_to_phone.bat to install ETC_EOS_RFR.apk directly via ADB for native experience.
  • iOS (iPad / iPhone): Open the web address in Safari, tap the "Share" button, and select "Add to Home Screen" to run in landscape full-screen PWA mode without browser address bars.

軟體簡介

ETC Cue 截圖記錄器是一款專為舞台燈光設計師與技術人員打造的專業截圖記錄工具。它能透過 OSC 協定與 ETC/EOS 燈控台通訊，在 Cue 完成或 Channel 設定時自動截取視訊畫面，並提供完整的專案管理與報告匯出功能。

圖 1：ETC Cue 截圖記錄器主介面

主要特色

🎯 Cue 模式

自動偵測 Cue 完成事件，截取舞台畫面並記錄 Cue 編號與時間

💡 CH 模式

支援 Chan 指令偵測，適用於記錄燈光參數設定場景

📹 視訊輸入

支援 USB 攝影機、RTSP 串流多種來源

🎬 視訊錄影

內建視訊錄影功能，同步記錄 Cue 時間戳

📊 完整記錄

自動記錄 Cue 編號、時間長度、截圖、備註等完整資訊

📁 專案管理

支援專案儲存/載入，方便管理多個演出專案

📄 報告匯出

一鍵匯出 Excel 與 PDF 報告，方便分享與歸檔

🔄 覆蓋模式

支援選取記錄後覆蓋更新，方便修正截圖

📡 sACN DMX 觸發

支援接收 sACN DMX 訊號，可設定觸發通道與閾值進行自動截圖

OSC 連線設定

軟體透過 OSC (Open Sound Control) 協定與 ETC/EOS 燈控台通訊，接收 Cue 與 Channel 指令。

燈控台設定

圖 6：ETC/EOS 燈控台 OSC 輸出設定

燈控台設定步驟

  1. 進入燈控台設定選單
  2. Setup>System setting>show control
  3. 啟用 OSC RX TX
  4. 設定目標 IP 為本軟體電腦的 IP 位址
  5. 設定 Port 為 8000（或您設定的連接埠）

軟體端設定

圖 7：軟體端 OSC 設定
設定項目 預設值 說明
OSC Port 8000 接收 OSC 訊息的連接埠
Console IP - 燈控台的 IP 位址（用於請求詳細資訊）
Console Port 3032 燈控台的 OSC 接收連接埠

⚠️ 重要提醒

請確保電腦與燈控台在同一網段，且 Windows 防火牆未阻擋 UDP Port 8000。

sACN DMX 觸發設定

軟體支援透過 sACN (Streaming ACN) 協議接收 DMX 訊號，可設定特定 DMX 通道作為截圖觸發條件，適合需要與燈光效果同步截圖的場合。

sACN 功能特色

📡 接收 sACN 訊號

自動接收網路中的 sACN DMX 訊號，無需額外硬體

🎯 自定義觸發通道

可指定任意 DMX 通道（1-512）作為觸發來源

⚡ 邊緣觸發機制

只在數值由低變高時觸發一次，避免重複截圖

🎮 手動觸發控制

可透過 DMX 訊號手動控制截圖時機，與燈光效果同步

sACN 設定步驟

設定流程

  1. 點擊選單「設定」→「開啟設定...」
  2. 在「sACN 設定」區啟用 sACN 接收功能
  3. 設定 Universe 編號（預設為 1）
  4. 設定觸發通道（1-512，例如：通道 1）
  5. 設定觸發閾值（0-255，例如：128）
  6. 點擊「確定」儲存設定

觸發邏輯說明

設定項目 預設值 說明
Universe 1 sACN Universe 編號（1-63999）
觸發通道 1 DMX 通道編號（1-512）
觸發閾值 128 當 DMX 值超過此數值時觸發（0-255）

邊緣觸發機制

軟體採用邊緣觸發機制，只在 DMX 數值由低變高時觸發一次截圖：

  • 當 DMX 值從 ≤ 閾值 變為 > 閾值：觸發截圖
  • 當 DMX 值持續 > 閾值：不重複觸發
  • 當 DMX 值從 > 閾值 變為 ≤ 閾值：重置觸發狀態

此機制確保每個燈光變化只會觸發一次截圖，避免重複記錄。

使用場景範例

範例：與燈光效果同步截圖

假設您想要在特定燈光效果觸發時自動截圖：

  1. 在燈控台上設定一個專門的 DMX 通道（例如通道 512）作為觸發信號
  2. 在軟體中設定 sACN Universe 為 1，觸發通道為 512，閾值為 1
  3. 在需要截圖的 Cue 中，將通道 512 設定為 255
  4. 當該 Cue 執行時，軟體會自動截取當下畫面

⚠️ 網路設定注意事項

  • 請確保電腦與發送 sACN 訊號的設備在同一網段
  • sACN 使用 Multicast 位址（239.255.0.0/16），請確保網路設備支援 IGMP
  • Windows 防火牆可能需要允許 sACN 相關的網路流量

內容與備註同步

軟體支援自動同步 ETC Eos 控台中的 Cue Label（名稱）與 Notes（備註/Node），確保記錄文檔與控台 show file 內容完全一致。

🏷️ Label 同步

自動獲取控台中的 Cue Label，顯示於表格的「名稱」或「標籤」欄位

📝 Notes/Node 同步

自動獲取控台中的 Cue Notes (或稱為 Node)，顯示於表格的「備註」欄位

功能運作機制

即時同步邏輯

  • 觸發時機：當軟體收到 OSC 訊息偵測到 Cue 執行時，會自動向控台發送請求以獲取詳細資訊。
  • 自動更新：若您在控台上修改了 Label 或備註，下次觸發該 Cue 時，軟體會自動更新記錄中的對應欄位。
  • 歷史記錄：匯出報表（Excel/PDF）時，會優先包含這些從控台同步回來的最新資訊。

⚠️ 設定要求

此功能需要確保「OSC 連線設定」中的 Console IP 與 Console Port 正確無誤，以便軟體能向控台發送請求訊號。

Cue 模式是軟體的主要工作模式，當燈控台執行 Cue 時自動截取畫面。

Cue 模式運作流程

自動截圖流程

  1. 軟體接收控台訊號
  2. 即時顯示當前 Cue 編號與剩餘時間

智慧更新機制

當相同 Cue 編號再次觸發時：

  • 若時間相同：不動作（避免重複記錄）
  • 若時間不同：自動更新時間並重新截圖

CH 模式操作

CH 模式適用於記錄燈光參數設定場景，當偵測到 Chan 指令時自動截圖。

圖 11：CH 模式介面，顯示當前 Chan 編號

CH 模式運作流程

自動截圖流程

  1. 軟體接收 Chan 指令（如 Chan 1、Chan 1 Thru 3）
  2. 即時顯示當前 Chan 編號
  3. 等待 Level 指令（如 @ Full、Level 50）
  4. 延遲 1 秒後自動截圖
  5. 記錄顯示在右側表格中

支援的 Chan 指令格式

指令格式 說明 範例
Chan X 單一 Channel Chan 1
Chan X + Y 多個 Channel 相加 Chan 1 + 5
Chan X Thru Y Channel 範圍 Chan 1 Thru 3

⚠️ 自動延遲機制

為確保燈光效果已完全呈現，軟體會在接收到 Level 指令後延遲 1 秒才執行截圖。

手動截圖功能

除了自動截圖外，軟體也提供手動截圖功能，方便補充記錄或修正截圖。

覆蓋更新模式

當表格中有選取列時，點擊「📷 手動截圖」會：

  • 只更新該列的截圖
  • 保留原有的 Cue/Chan 編號與其他資訊
  • 適合修正拍攝效果不佳的截圖

透過 sACN DMX 訊號手動觸發

當啟用 sACN 功能後，您也可以透過 DMX 訊號來手動控制截圖時機：

sACN 手動觸發流程

  1. 在設定中啟用 sACN 接收功能並設定觸發通道
  2. 當設定的 DMX 通道數值超過閾值時，軟體會自動截圖
  3. 只會更新截圖，不會改變 Cue/Chan 資訊

專案管理

軟體提供完整的專案管理功能，方便管理多個演出專案。

專案檔案格式

專案檔案 (.json)

專案檔案包含所有記錄資訊，但不包含實際的截圖與錄影檔案。截圖與錄影檔案會儲存在獨立的資料夾中。

專案操作

操作 選單路徑 快捷鍵
新增專案 檔案 → 新增專案 Ctrl+N
開啟專案 檔案 → 開啟專案 Ctrl+O

截圖檔案與錄影檔案不會儲存在專案檔案中。移動或分享專案時，請確保一併複製 screenshots 與 recordings 資料夾。

故障排除

常見問題

Q1: 無法連接到燈控台

  • 確認 IP 位址正確（可使用 ping 測試）
  • 確認 Port 號與燈控台設定一致
  • 檢查 Windows 防火牆是否阻擋 UDP Port 8000
  • 確認燈控台已啟用 OSC 輸出功能

Q2: 視訊來源無法連接

  • 確認 USB 攝影機已正確連接
  • 確認 NDI 來源已開啟並在同一網段
  • 確認 RTSP 串流 URL 正確
  • 嘗試重新啟動軟體

Q3: Cue 模式無法自動截圖

  • 確認已點擊「開始記錄」按鈕（按鈕應為紅色）
  • 確認 OSC 連線正常（狀態列顯示「OSC 已啟動」）
  • 確認燈控台正在發送 Cue 訊號
  • 檢查是否切換到 Cue 模式（非 CH 模式）

Q4: CH 模式無法自動截圖

  • 確認已點擊「開始記錄」按鈕
  • 確認已切換至 CH 模式
  • 確認燈控台發送的 Chan 指令格式正確
  • 確認 Chan 指令後有 Level 指令（如 @ Full）

Q5: 匯出 PDF 中文顯示為方塊

  • 確認系統已安裝「微軟正黑體」字型
  • 若未安裝，軟體會自動嘗試使用其他中文字型
